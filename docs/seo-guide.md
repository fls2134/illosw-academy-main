# SEO 등록 체크리스트

## Google Search Console
- [ ] https://search.google.com/search-console 접속
- [ ] URL 접두어로 사이트 추가
- [ ] HTML 파일 다운로드 → `public/` 폴더에 업로드 → push
- [ ] 소유권 확인 버튼 클릭
- [ ] Sitemaps 메뉴에서 sitemap.xml 제출

## Naver Search Advisor
- [ ] https://searchadvisor.naver.com 접속
- [ ] 웹마스터 도구 → 사이트 등록
- [ ] HTML 파일 다운로드 → `public/` 폴더에 업로드 → push
- [ ] 소유권 확인 버튼 클릭
- [ ] 요청 → 사이트맵 제출
